# Besluiten

Vastgelegd op 4 september 2026. De codes verwijzen naar het keuzeplan
(`docs/keuzeplan.html`), waar per beslissing de alternatieven en hun gevolgen
staan.

| | Besluit |
|---|---|
| **A1** | Maatwerk bouwen |

## Structuur en geld

| | Besluit |
|---|---|
| **B1** | Klant → project → projectonderdeel; geen subtaken |
| **B2** | De volledige tariefzoekvolgorde van zeven niveaus |
| **B3** | Interne kostprijs als vast bedrag per medewerker per periode |

| | Besluit |

## Wat hiervan nog open staat

- **E2** — welk boekhoudpakket gebruiken jullie? Dat bepaalt of een directe
  koppeling later de moeite waard is.
- **C3** — rijdt iemand in een auto van de zaak? Dan gelden er zwaardere eisen
  aan de rittenregistratie; dat is een vraag voor de boekhouder.
- **B3** — de kostprijs per medewerker moet nog ingevuld worden. Een schatting
  is genoeg om te beginnen.
